# Android 1.1.0 验证

日期：2026-10-19。测试环境：Android 15 / API 35 x86_64 模拟器，Pixel 5 尺寸。

## 本次修改

- 月历年份、月份入口使用自定义底部面板，支持年份分组、月份网格、回到本月、选中状态、关闭和安卓返回键。
- 标注放假“休”、调休“班”，调休周末恢复工作日文字颜色；日期详情同步说明。数据覆盖 2002—2026 年，其他年份提示未收录。
- 左右真实触摸切换月份，识别滑动方向、区分纵向滚动、防止滑动结束误点日期，支持跨年与查询边界。
- 原生窗口绘制到底部，系统导航栏透明、取消对比度遮罩；网页按系统真实导航区高度留出按钮安全边距，适配深浅主题。

## 检查

- Release 和 Release AndroidTest 编译通过，测试 APK 与正式 APK 使用相同签名。
- 在旧版 1.0.0 正式 APK 内保存记事，再用 1.1.0 覆盖安装，新的进程读取到原记事；测试记录已清理。
- 24 项设备检查包含原有 9 项功能，以及年月面板、国庆休息标记、调休工作日、春节连续九天、未收录年份、实际左右触摸、纵向滚动、跨年、1901/2100 年边界、底部安全区、深色沉浸布局和面板返回关闭。
- `node verify-holidays.cjs` 将 2026 年全部 39 条放假/调休记录与国务院办公厅公布的日期逐条对照，检查通过。来源：[国办发明电〔2025〕7号](https://www.beijing.gov.cn/zhengce/zhengcefagui/202511/t20251104_4258873.html)。
- 生成并检查主界面、月份面板、年份面板、深色模式的模拟器截图。

签名沿用 1.0.0。APK 不增加网络或其他敏感权限。实体手机兼容性尚未验证，历史年份数据来自随包附带的 lunar-javascript 1.7.7；不推算未收录年份的调休安排。
