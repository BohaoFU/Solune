# Android 1.2.0 验证

日期：2026-10-19。测试环境：Android 15 / API 35 x86_64 模拟器，Pixel 5 尺寸。测试使用签名后的正式 Release APK。

## 本次变化

- 接入提莫公开的年度节假日接口。后台 HTTPS 请求、固定服务域名、超时和响应大小限制、年份/日期/布尔字段校验。原生桥只接受年份和是否手动更新，不接受外部 URL。
- 有效年度数据写入单独的 SharedPreferences 缓存，优先于内置安排。空数据、未收录年份、格式错误和网络失败保留已有安排。网络状态及最近更新时间可查看，也可手动更新。
- 年份、农历年月日改为网格面板，公历日期改为带农历的日历面板。查询、记事、帮助、开源许可、删除确认统一底部面板，兼顾深浅色、可滚动内容、多层面板返回和系统底部安全区。
- 版本号 1.2.0 / versionCode 3，沿用原签名。新增普通 INTERNET 权限，农历与记事仍可离线使用。

## 已完成检查

- Release、Release AndroidTest 构建和 Release Lint 通过。
- 正式包签名和 ZIP 对齐校验通过；证书 SHA-256 与旧版本一致：`62cef9c7ba88d9e3b931839de77d892b8804a064730bf2e6f2daf35a0b36eff3`。
- 先安装 1.1.0 并保存记事，再覆盖安装 1.2.0，在新进程内读到原有记事；测试记录已清理。
- 真正向公共服务发起 HTTPS 请求，成功缓存 2026 年 39 条放假/补班记录并显示到日历。将 API 实际返回的全部 39 条日期/休息属性与官方通知逐条核对通过，见 `verify-holidays.cjs`。
- 关闭模拟器 Wi-Fi 与移动数据并重启应用进程，仍读取到下载的 39 条缓存；日期详情使用接口中的“后补班”名称，确认采用已下载缓存。
- 37 项界面回归通过：原有农历、转换、记事、主题、滑动、安全区，以及新年份网格、农历闰月选择、日期面板、取消保留原值、闰年日期收敛、多层返回、删除取消/确认、帮助卡片、开源许可、深色面板等。
- 独立仓库检查通过：完整响应解析、补班属性、未公布年份、错误年份/日期拒绝、缓存写盘、请求限频、模拟断网、空响应保留缓存、仓库重建后读回。
- 实际触摸打开记事键盘，检查焦点、滚动到保存按钮，并通过真实点击保存成功；测试记事已清理。
- 截图检查日期面板、农历月份网格、记事、删除确认、帮助、开源许可和深色日期面板。帮助长面板曾出现 WebView 背景穿透，改为内部滚动容器后截图确认修复。

真实接口测试使用测试专用 HTTP CONNECT 转发解决当前主机 VPN/DNS 与模拟器不兼容的问题，TLS 正常校验，未替换服务器响应。生产 APK 没有代理设置。

实体手机兼容性尚未验证。网络数据属于第三方整理，更新速度取决于服务收录；未公布年份不推算调休。
