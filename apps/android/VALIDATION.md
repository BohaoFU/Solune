# Android 1.0.0 版本验证（历史记录）

日期：2026-10-19。

构建环境：JDK 17、Gradle 8.14、AGP 8.11.1、Android SDK 35。Release、Debug、AndroidTest 均离线构建成功；Release lint vital 通过。

Android 15 / API 35 x86_64 模拟器上通过以下 9 项核心检查：

1. 无网络权限时从 APK 内置资源启动，月历显示 42 个日期。
2. 2026-10-19 正确显示农历九月初十。
3. 切换到下个月，详情与月份同步。
4. 公历 2026-02-17 转换为农历正月初一。
5. 农历 2025 年闰六月初一转换为公历 2025-07-25。
6. 记事写入成功并在日期详情显示。
7. WebView 页面重新加载后，记事仍显示。
8. 深色主题切换正常，手机宽度无横向溢出。
9. 安卓返回键可关闭日期查询弹窗。

额外跨进程检查：先通过应用表单保存记事，结束 Activity，再执行 `am force-stop`，重新启动新的进程并读取，记事仍存在。测试数据已清理。

安卓记事使用原生 SharedPreferences 同步写盘，保存成功后才显示成功提示，避免 WebView 自身存储异步刷新导致突然结束进程时丢失刚保存的内容。

正式包已完成 APK v2 签名与 ZIP 对齐验证。Manifest 无 INTERNET、存储、相机、通讯录或通知权限。没有 ARM 真机连接，实体手机兼容性尚未验证；代码不包含依赖特定 CPU 架构的原生二进制库。
